## 1. 公司注册

### 1.1 法律依据

| 项目 | 内容 |
|------|------|
| 核心法律 | CAMA 2020（2020年8月7日签署生效） |
| 最近修订 | 《2023年商业便利（杂项规定）法案》(Business Facilitation (Miscellaneous Provisions) Act 2023)，2023年2月签署 |
| 2024-2026新修订 | **无新的独立修订法案**（截至2026年8月） |
| 确定性 | ✅ 已确认 |

### 1.2 公司类型与设立条件

| 类型 | 最低股东数 | 最低董事数 | 最低股本 | 公司秘书 |
|------|-----------|-----------|---------|---------|
| 私人有限公司（LTD） | 1 | 1（小公司）/ 2（非小公司） | ₦10,000（法定最低） | 必须 |
| 公众有限公司（PLC） | 2 | 2 | ₦2,000,000（已发行） | 必须 |
| 单人公司（SPC） | 1 | 1 | ₦10,000 | 必须 |
| 外商独资/合资（WOS/JV） | 1 | 2 | ₦100,000,000（实际要求） | 必须 |

> ⚠️ **外资企业关键提示**：虽然CAC注册层面法定最低股本仅为₦10,000，但联邦内政部在核发营业执照（Business Permit）和外籍员工配额时，严格要求实缴资本至少₦100,000,000。这是实际运营门槛。

### 1.3 登记流程

1. **名称预留**：通过CAC在线门户（pre.cac.gov.ng）提交，获批后60天有效
2. **在线注册**：填写预注册表格，上传MEMART、董事/股东信息
3. **支付费用**：注册费 + 印花税
4. **审核发证**：CAC审核通过后颁发电子注册证书
5. **后续登记**：
   - FIRS获取TIN（税务识别号）
   - NIPC注册（外资企业必须）
   - 申请营业执照（Business Permit，外资企业必须）
   - 银行开户 + 获取CCI（资本导入证书）

### 1.4 行业准入限制

| 限制类型 | 行业 | 说明 |
|---------|------|------|
| 完全禁止（负面清单） | 武器弹药、麻醉药品、军事服装 | 对所有投资者（含本国）禁止 |
| 本地化要求 | 石油天然气 | 需符合本地内容法案，通常需与NNPC或当地公司合资 |
| 行业许可 | 银行、保险、电信、矿业 | 需向CBN/NAICOM/NCC等申请特定许可证 |
| 地方要求 | 彩票/博彩（部分州） | 如拉各斯州可能要求本地合作方持股≥15% |
| 外籍员工 | 所有行业 | 需申请Expatriate Quota，限制外籍岗位数量 |

### 1.5 分支机构（外国公司）

| 项目 | 内容 |
|------|------|
| 基本原则 | CAMA 2020第78条：外国公司必须在尼日利亚注册独立子公司方可开展业务 |
| 例外（第80条） | 受联邦政府邀请执行特定项目、国际组织贷款项目、出口促进活动、特定工程咨询公司 |
| 确定性 | ✅ 已确认 |

> ⚠️ **外资影响**：尼日利亚不承认外国公司直接设立"分公司"经营，必须注册本地子公司。例外情况需向联邦政府正式申请豁免许可。

### 1.6 2024-2026年变更

| 变更 | 时间 | 内容 | 确定性 |
|------|------|------|--------|
| CAC加强执法 | 2026年7-8月 | CAC发布公共通知，将严格执行CAMA第304条和第729条（商业文件披露），2026年8月1日起加强处罚 | ✅ 已确认 |
| 商业便利法案修订 | 2023年2月（现行有效） | AGM灵活性、增加股本程序简化、外国公司豁免条件扩展 | ✅ 已确认 |

## 2. 董事资格

### 2.1 基本要求

| 项目 | 本地公司 | 外资公司（WOS/JV） |
|------|---------|-------------------|
| 最低人数 | 1（小公司）/ 2（非小公司） | 2（外资公司不得为小公司） |
| 国籍限制 | 无 | 无法律限制 |
| 居住地要求 | 无 | 无法律强制要求，但实务中强烈建议 |
| 公司秘书 | 必须 | 必须（须为尼日利亚执业律师或特许秘书） |

### 2.2 取消资格情形（CAMA 2020第283条）

以下人员**不得**担任公司董事：

| 序号 | 情形 | 说明 |
|------|------|------|
| 1 | 未成年人 | 未满18岁 |
| 2 | 精神失常者 | 被法院认定为精神失常或心智不健全 |
| 3 | 被罢免者 | 根据CAMA第288条被罢免的董事 |
| 4 | 未解除破产人 | 未解除破产状态的人（除非获得法院许可） |
| 5 | 欺诈/不当行为受限者 | 被法院裁定存在欺诈行为或违反受托责任而被禁止担任董事 |
| 6 | 法人团体 | 法人本身不能担任董事（但可委派代表） |

### 2.3 职务自动终止

董事在任期间出现以下情况，职务自动终止：
- 变得精神失常
- 被宣告破产
- 被法院禁止担任董事
- 连续缺席董事会会议超过规定期限（依章程规定）

### 2.4 外资企业实务建议

| 项目 | 说明 |
|------|------|
| 当地董事 | 法律未强制要求，但实务中强烈建议至少1名当地居民董事 |
| 原因 | 银行开户、税务合规、CAC手续、营业执照申请均需当地实际存在 |
| 外籍董事签证 | 需申请STR Visa → CERPAC（居住和工作许可） |
| 确定性 | ✅ 已确认（法律层面无居住地要求）；⚠️ 建议复核（实务操作标准可能变化） |

### 2.5 2024-2026年变更

| 变更 | 内容 | 确定性 |
|------|------|--------|
| 无重大立法变更 | CAMA 2020第283条在2024-2026年未修订 | ✅ 已确认 |

## 3. 股权转让

### 3.1 基本规则

| 项目 | 内容 |
|------|------|
| 法律依据 | CAMA 2020 |
| 形式要求 | 必须书面签署转让协议 |
| 登记要求 | 更新股东名册 + 向CAC备案变更 |
| 印花税 | 转让文件须缴纳印花税，否则法律上可能无效 |
| 确定性 | ✅ 已确认 |

### 3.2 优先购买权（Pre-emptive Rights）

| 项目 | 内容 |
|------|------|
| 新股发行 | CAMA第142条：必须优先向现有股东按持股比例发售 |
| 现有股份转让 | 私营公司章程通常包含优先购买权条款，须先向现有股东提供 |
| 法律效力 | 章程/股东协议中的优先购买权条款具有法律约束力 |
| 确定性 | ✅ 已确认 |

### 3.3 外资持股限制

| 项目 | 内容 |
|------|------|
| 一般原则 | 允许100%外资持股，无强制本地合作方要求 |
| 负面清单 | 武器弹药、麻醉药品、军事服装（对所有投资者禁止） |
| 行业限制 | 石油天然气（本地内容要求）、博彩（部分州要求本地持股） |
| 最低股本 | 外资参股公司实际要求₦100,000,000实收资本 |
| 确定性 | ✅ 已确认 |

### 3.4 外资股权转让特别程序

| 步骤 | 说明 |
|------|------|
| 1. 尽职调查 | 审查公司章程，确认限制性条款和优先购买权机制 |
| 2. 触发优先购买权 | 按章程规定向现有股东发出书面转让通知 |
| 3. 签署协议 + 缴税 | 签署股份转让协议，缴纳印花税 |
| 4. 公司内部登记 | 更新股东名册，向CAC递交变更申请 |
| 5. 资本导入 | 通过授权交易商（银行）办理，获取CCI |
| 6. NIPC备案 | 更新NIPC登记信息 |
| 7. 重大持股披露 | 获得实质性控制权后7天内须向公司披露 |

### 3.5 2024-2026年变更

| 变更 | 内容 | 确定性 |
|------|------|--------|
| 无重大立法变更 | 股权转让基本规则在2024-2026年未修订 | ✅ 已确认 |
| 实务关注 | CAC加强合规执法，对文件披露要求更严格 | ⚠️ 建议复核 |

## 4. 税务要求

### 4.1 企业所得税（CIT）

#### 当前有效税率（2024-2025年度）

| 企业规模 | 年营业额 | 税率 |
|---------|---------|------|
| 小企业 | ≤ ₦25,000,000 | **0%** |
| 中型企业 | ₦25,000,001 – ₦100,000,000 | **20%** |
| 大型企业 | > ₦100,000,000 | **30%** |

#### ⚡ 2026年1月1日起生效 — NTA 2025重大改革

| 变更 | 内容 | 生效日期 |
|------|------|---------|
| 小企业门槛提高 | 年营业额≤₦100,000,000 且固定资产≤₦250,000,000 → 免CIT/CGT/发展税 | 2026-01-01 |
| 发展税（Development Levy） | 统一4%取代教育税(TET)、NASENI税、IT税等多项征费 | 2026-01-01 |
| 最低有效税率（ETR） | 大型跨国企业（年营业额>₦500亿或集团全球营业额≥€7.5亿）适用15%最低税率 | 2026-01-01 |
| 资本利得税上调 | 从10%上调至30%，与标准CIT税率一致 | 2026-01-01 |

> **来源**：Nigeria Tax Act 2025 (NTA 2025)，2025年6月26日总统签署  
> **确定性**：✅ 已确认

### 4.2 预提税（WHT）

| 项目 | 内容 |
|------|------|
| 新规 | 《2024年源头扣缴税条例》(Deduction of Tax at Source (Withholding) Regulations 2024) |
| 生效日期 | 2025年1月1日 |
| 小企业豁免 | 月交易额≤₦2,000,000 且供应商有有效TIN → 免除代扣代缴 |
| TIN强制 | 收款人无TIN → 预扣税税率翻倍 |
| 确定性 | ✅ 已确认 |

### 4.3 增值税（VAT）

| 项目 | 内容 |
|------|------|
| 标准税率 | **7.5%** |
| 进项税抵扣 | 扩大至服务和固定资产的进项税（与应税供应相关） |
| 零税率/豁免 | 基本食品、医疗用品、教育书籍等 |
| 数字化合规 | FIRS强制要求电子发票和实时增值税申报系统 |
| 确定性 | ✅ 已确认 |

### 4.4 转让定价（TP）

| 项目 | 内容 |
|------|------|
| 核心法规 | 《2018年所得税（转让定价）条例》 |
| 基本原则 | 独立交易原则（Arm's Length Principle） |
| 文档门槛 | 关联交易总额<₦300,000,000可暂不准备，但FIRS要求时须90天内提交 |
| 申报时限 | 公司成立后18个月内或会计年度结束后6个月内（以较早者为准） |
| 利息扣除限制 | 关联方借款利息≤EBITDA的30% |
| 特许权使用费/服务费限制 | 支付给外国关联方≤EBITDA的5%，且通常需NOTAP预先批准 |
| 处罚 | 未提交TP申报：每日₦25,000或₦10,000,000与违规金额1%之间较高者 |

#### ⚡ 2024-2025年变更

| 变更 | 内容 | 生效日期 | 确定性 |
|------|------|---------|--------|
| 预约定价安排（APA）指南 | FIRS发布Information Circular No. 2024/006，引入单边/双边/多边APA，最长期3年 | 2025-01-01 | ✅ 已确认 |

### 4.5 税收优惠

| 优惠类型 | 内容 | 适用条件 |
|---------|------|---------|
| 小企业CIT豁免 | 营业额≤₦25M（现行）/ ≤₦100M（2026起） | 非专业服务公司 |
| 先锋行业优惠 | Pioneer Status Income Tax Holiday（3-5年免税期） | 需向NIPC申请，指定行业 |
| 自由贸易区 | 在FTZ内注册的企业享有CIT豁免等优惠 | 需在FTZ内运营 |
| 研发扣除 | 符合条件的研发支出可加计扣除 | 需满足FIRS规定条件 |
| 确定性 | ⚠️ 建议复核（先锋行业具体清单可能更新） |

### 4.6 外资企业税务影响

| 影响点 | 说明 |
|--------|------|
| 利润汇出 | 法律保障在满足税务义务后可汇出利润/股息，须通过授权交易商 |
| CCI必要性 | 资本导入证书是未来汇回的前提条件 |
| 预提税翻倍风险 | 无TIN则WHT税率翻倍，外资企业务必确保TIN有效 |
| 转让定价重点 | FIRS重点关注：持续亏损、大量关联交易、低税区交易、数字经济 |
| NTA 2025影响 | 大型跨国企业需关注15%最低有效税率（2026年起） |

## 5. 公司年审

### 5.1 年报提交（Annual Returns）

| 项目 | 内容 |
|------|------|
| 提交义务 | 所有注册公司（含不活跃公司）均须提交 |
| 新公司豁免 | 注册后前18个月无需提交 |
| 常规截止 | AGM后42天内（实务中通常为每年6月30日前提交上一年度年报） |
| 提交方式 | CAC在线门户（pre.cac.gov.ng） |
| 逾期后果 | 罚款 + 可能被标记为"Inactive"或被注销 |
| 确定性 | ✅ 已确认 |

### 5.2 审计要求

| 公司类型 | 是否需要审计 | 条件 |
|---------|------------|------|
| 小公司 | **豁免** | 满足以下至少2项：年营业额≤₦120M、净资产≤₦60M、员工≤50人 |
| 非小公司 | **必须** | 须任命外部审计师，提交经审计的财务报表 |
| 银行/保险 | **必须** | 无论规模，均须审计 |
| 外资公司 | **必须** | 外资公司不得归类为"小公司"，必须审计 |
| 确定性 | ✅ 已确认 |

### 5.3 合规申报

| 申报类型 | 频率 | 截止日期 | 说明 |
|---------|------|---------|------|
| CAC Annual Returns | 年度 | AGM后42天（实务~6月30日） | 含财务报表/审计报告 |
| CIT申报 | 年度 | 会计年度结束后6个月内 | 含经审计/简化财务报表 |
| VAT申报 | 月度 | 次月21日前 | 含进项/销项税明细 |
| WHT申报 | 月度 | 次月21日前 | 代扣代缴税款 |
| TP申报/披露 | 年度 | 会计年度结束后6个月内 | 关联方交易披露 |
| 确定性 | ✅ 已确认 |

### 5.4 2024-2026年变更

| 变更 | 内容 | 确定性 |
|------|------|--------|
| CAC加强执法 | 2026年8月1日起加强商业文件披露处罚（第304条、第729条） | ✅ 已确认 |
| 电子发票强制化 | FIRS推进电子发票和实时VAT申报系统 | ✅ 已确认 |
| NTA 2025整合 | 2026年起统一税务框架，数字化合规要求提升 | ✅ 已确认 |

## 6. 注销

### 6.1 清算方式

| 方式 | 适用情形 | 说明 |
|------|---------|------|
| 成员自愿清算 | 公司有偿债能力 | 董事作出偿债能力法定声明，成员通过特别决议（≥75%多数） |
| 债权人自愿清算 | 公司无偿债能力 | 债权人参与，可能任命清算人 |
| 强制清算 | 法院命令 | 由债权人/股东/CAC向联邦高等法院申请 |
| 行政注销（Strike-off） | 长期不活跃 | CAC主动注销未提交年报或长期不活跃的公司 |
| 确定性 | ✅ 已确认 |

### 6.2 自愿清算流程

| 步骤 | 内容 | 时间 |
|------|------|------|
| 1. 董事会评估 | 评估财务状况，提出清算决议 | — |
| 2. 特别决议 | 成员通过特别决议（≥75%） | — |
| 3. 任命清算人 | 接管资产、清偿债务、分配剩余资金 | — |
| 4. 通知CAC | 决议后14天内通知CAC | 14天 |
| 5. 公告 | 在官方公报和两份全国性报纸上刊登公告 | — |
| 6. 最终账目 | 清算人准备最终账目，召开最终会议 | — |
| 7. 注销登记 | 向CAC提交回报 | — |
| 8. 正式解散 | 回报登记后3个月视为正式解散 | ~3个月 |

### 6.3 税务注销

| 项目 | 内容 |
|------|------|
| 前置条件 | 须结清所有税务义务（CIT、VAT、WHT等） |
| FIRS清算 | 需向FIRS申报最终税务状况，获取税务清算确认 |
| 确定性 | ⚠️ 建议复核（具体清算确认流程可能因FIRS内部规定而异） |

### 6.4 债务处理

| 优先级 | 债务类型 |
|--------|---------|
| 1 | 清算费用和成本 |
| 2 | 员工工资和福利 |
| 3 | 政府税款（含CIT、VAT） |
| 4 | 担保债权人 |
| 5 | 普通无担保债权人 |
| 6 | 股东（按持股比例分配剩余资产） |

### 6.5 时间周期

| 情形 | 预计时间 |
|------|---------|
| 有偿债能力的自愿清算（简单） | 6-12个月 |
| 无偿债能力的清算 | 12-24个月或更长 |
| 行政注销（CAC主动） | 不确定，取决于CAC执法节奏 |
| 确定性 | ⚠️ 建议复核 |

### 6.6 外资企业特别注意

| 项目 | 说明 |
|------|------|
| 利润汇出 | 清算所得汇出前须完成所有税务清算 |

## 风险提示与建议

### 高优先级关注

1. **NTA 2025过渡期**（2026年1月1日生效）：企业需重新评估税务筹划，特别是小企业门槛变化和最低有效税率
2. **CCI管理**：外资企业务必保存好资本导入证书，这是利润汇出的前提
3. **TIN合规**：确保TIN有效，否则WHT税率翻倍

### 建议复核事项

1. 行业准入限制清单是否更新（特别是石油天然气、博彩行业）
2. 先锋行业优惠（Pioneer Status）具体适用行业清单
3. CBN最新外汇政策细节（特别是出口收益汇回时限）
4. 各州层面的附加税费和合规要求
