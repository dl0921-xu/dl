## 1. 公司注册

### 1.1 当前有效规则

| 项目 | 本地公司 | 外商独资（WOS） | 合资（JV） | 分支机构 |
|------|----------|-----------------|------------|----------|
| **最低注册资本** | 按行业/实体类型 | USD 200,000（一般）；USD 100,000（工程/ICT/咨询等特定行业） | USD 150,000 | 同 WOS 标准 |
| **股东/成员人数** | PLC: 1-50人；Share Company: ≥5人 | 同左 | 同左 | 无独立股东要求（母公司承担全责） |
| **董事人数** | PLC: ≥1人；Share Company: 3-13人 | 同左 | 同左 | 需任命常驻负责人（Manager），需符合董事资格要求 |
| **注册机构** | Ministry of Trade and Regional Integration (MoTRI) | EIC → MoTRI | EIC → MoTRI | EIC → MoTRI |
| **注册办公地址** | 必须 | 必须 | 必须 | 必须 |
| **行业准入限制** | 无特殊限制 | 部分行业仍有限制（见1.2） | 部分行业仍有限制 | 须与母公司经营范围一致 |

### 1.2 注册流程（2024-2025更新）

1. **名称预留**：通过 ETRADE 门户 (etrade.gov.et) 提交3个候选名称
2. **文件认证**：组织章程大纲 (MoA) 须经 Document Authentication and Registration Service (DARS) 认证
3. **投资许可**（外资适用）：向 EIC 申请投资许可（通过 eInvest 系统）
4. **商业登记**：向 MoTRI 申请商业登记证书，取得法人资格
5. **税务登记**：获取 Taxpayer Identification Number (TIN)
6. **营业执照**：根据行业申请相应运营许可

### 1.3 2024-2026年重大变更

| 变更 | 详情 | 来源 | 确定性 |
|------|------|------|--------|
| **贸易领域大幅开放** | Directive 1082/2025 取代 1001/2024：出口（含咖啡、油籽、皮革等战略商品）、进口（除化肥/石油外）、批发（除化肥外）、零售（首次开放，门槛 USD 2.5M）均向外资开放 | EIC Directive 1082/2025 | ✅ 已确认 |
| **银行业开放** | 允许外资通过子公司/分支机构/参股方式进入，外资持股上限40%-49% | Banking Proclamation 1360/2025 (2025-03) | ✅ 已确认 |
| **经济特区法** | 新法律框架吸引投资，促进贸易便利化 | Proclamation 1322/2024 (2024-04) | ✅ 已确认 |
| **一人公司 (OPC)** | 2021年商法典引入，允许单一股东设立有限公司 | Commercial Code 1243/2021 | ✅ 已确认 |
| **LLP（有限责任合伙）** | 新增实体类型，适用于专业服务 | Commercial Code 1243/2021 | ✅ 已确认 |
| **物流领域开放** | 取消货运代理行业外资持股限制 | 2026年最新政策 | ⚠️ 建议复核 |
| **尽职调查准入** | 从财务阈值/结构性要求转向尽职调查报告模式 | Directive 1082/2025 | ✅ 已确认 |

### 1.4 外资特别影响

- 🟢 **重大利好**：贸易领域（进出口、批发、零售）50年来首次向外资开放
- 🟢 **银行业准入**：外国银行可设立子公司或分支机构
- 🟡 **零售门槛**：USD 2.5M 最低实缴资本（单一品牌零售商可酌情降低）
- 🟡 **资本进口证明**：外资必须通过授权银行汇入资本，获取资本进口证书（未来利润汇出的前提）
- 🔴 **土地国有**：所有土地为国有，外资仅可通过租赁获得使用权（最长99年）

## 2. 董事资格

### 2.1 当前有效规则

| 项目 | PLC（私人有限公司） | Share Company（股份公司） |
|------|---------------------|--------------------------|
| **最低董事人数** | ≥1人 | 3-13人 |
| **本地居民要求** | 无明确法定本地居民要求 | 无明确法定本地居民要求 |
| **持股要求** | 无要求 | 非股东董事可担任，但不得超过董事会总人数的1/3 |
| **法人董事** | 允许（需指定自然人代表） | 允许（需指定自然人代表） |
| **董事长要求** | 不适用 | 必须为股东；不得参与日常经营管理 |

### 2.2 任职资格（Commercial Code Art. 297）

- ✅ 具有完全法律行为能力（成年）
- ✅ 品行良好
- ✅ 无犯罪记录（特别是背信、盗窃、抢劫等相关犯罪）

### 2.3 Disqualified 情形

| 情形 | 说明 |
|------|------|
| **犯罪记录** | 因背信、盗窃、欺诈等定罪者不得担任董事 |
| **利益冲突** | 存在直接或间接利益冲突的事项中不得投票 |
| **竞业禁止** | 未经披露和授权，不得从事与公司竞争的业务 |
| **滥用职权** | 利用职权谋取私利或制造利益冲突可被解职 |

### 2.4 董事责任

- 对公司负有注意义务和勤勉义务
- 因违反职责造成损害的，承担连带赔偿责任
- 免除董事过失责任的协议无效

### 2.5 2024-2026年变更

| 变更 | 详情 | 确定性 |
|------|------|--------|
| 无重大变更 | 2021年商法典修订后，董事资格规则在2024-2026年间未见重大修订 | ✅ 已确认 |

### 2.6 外资特别影响

- 🟢 **无本地居民强制要求**：外资企业董事无需为埃塞俄比亚居民
- 🟢 **非股东可任董事**：可聘请外部专业人士，但股份公司中不超过1/3
- 🟡 **分支机构负责人**：须符合董事资格要求，建议确认是否需常驻

## 3. 股权转让

### 3.1 当前有效规则

| 项目 | 本地公司 | 外商独资（WOS） | 合资（JV） | 分支机构 |
|------|----------|-----------------|------------|----------|
| **外资持股限制** | 不适用 | 多数行业100%可持 | 按协议 | 不适用 |
| **转让审批** | 内部审批+登记 | EIC 审批 | EIC 审批 | 不适用 |
| **优先购买权** | 商法典/章程规定 | 商法典/章程规定 | 商法典/章程规定 | 不适用 |
| **登记变更** | MoTRI 商业登记 | EIC + MoTRI 双重登记 | EIC + MoTRI 双重登记 | 不适用 |

### 3.2 外资持股限制（2024-2026最新）

| 行业 | 外资持股上限 | 备注 |
|------|-------------|------|
| 一般贸易（进出口/批发） | 100% | Directive 1082/2025 开放 |
| 零售贸易 | 100% | 需满足 USD 2.5M 最低实缴资本 |
| 银行业 | 40%-49% | NBE 规定，需具体确认 |
| 特定敏感行业（部分矿业等） | 可能限制 49% 或 75% | ⚠️ 建议复核具体行业 |
| 建筑/工程/咨询 | 100% | 最低资本 USD 100,000 |
| 货运代理 | 100% | 2026年取消限制 |

### 3.3 股权转让流程（外资）

1. 向 EIC 提交股权转让申请
2. 提供尽职调查报告（财务稳健性、合规性、反洗钱记录）
3. EIC 审批
4. 完成商业登记变更
5. 如涉及外汇汇出，需通过授权银行办理

### 3.4 2024-2026年重大变更

| 变更 | 详情 | 来源 | 确定性 |
|------|------|------|--------|
| **贸易行业全面开放** | 进出口、批发、零售向外资开放（此前长期限制） | Directive 1082/2025 | ✅ 已确认 |
| **尽职调查替代业绩考核** | 准入从财务阈值转向合规尽职调查 | Directive 1082/2025 | ✅ 已确认 |
| **物流领域开放** | 货运代理外资持股限制取消 | 2026年政策 | ⚠️ 建议复核 |

### 3.5 外资特别影响

- 🟢 **持股限制大幅放宽**：多数行业已允许100%外资持股
- 🟡 **EIC 审批仍为必须**：所有外资股权转让须经 EIC 批准
- 🟡 **外汇管制**：转让所得汇出需满足 NBE 外汇指令要求
- 🔴 **敏感行业仍有限制**：部分矿业、国防等领域仍有持股比例上限

## 4. 税务要求

### 4.1 企业所得税 (CIT)

| 项目 | 税率/规则 | 备注 |
|------|----------|------|
| **标准税率** | 30% | 适用于一般企业 |
| **最低替代税 (AMT)** | 营业额的 2.5% | 🆕 2025年新增；如应纳所得税低于营业额2.5%，按2.5%征收 |
| **AMT 抵免** | 可向后结转5年 | 用于抵扣未来所得税 |
| **纳税年度** | 7月8日 - 次年7月7日 | 变更需税务部门书面批准 |
| **申报截止** | 会计年度结束后4个月内 | 即约11月7日前 |

### 4.2 预提税 (Withholding Tax)

| 类型 | 税率 | 变更说明 |
|------|------|----------|
| **股息** | 15% | 🆕 从10%提高至15%（2025-07起） |
| **未分配利润** | 15% | 🆕 从10%提高至15%（2025-07起） |
| **利息（非居民）** | 15% | 🆕 2025年调整 |
| **特许权使用费（居民）** | 15%（文化类10%） | 🆕 2025年调整 |
| **特许权使用费（非居民）** | 5%-15% | 视具体类型 |
| **本地采购（商品 >20,000 ETB）** | 3% | 🆕 从2%提高至3% |
| **本地采购（服务 >10,000 ETB）** | 3% | 🆕 从2%提高至3% |

### 4.3 增值税 (VAT)

| 项目 | 规则 |
|------|------|
| **标准税率** | 15% |
| **注册门槛** | 年应税销售额 >200万 ETB |
| **数字服务** | 🆕 非居民数字服务商年销售>200万 ETB 须登记缴纳 VAT（Proclamation 1341/2024） |
| **SEZ 优惠** | 进出经济特区的货物享受零关税+零VAT |

### 4.4 转让定价

| 项目 | 规则 |
|------|------|
| **法规依据** | Income Tax Proclamation 979/2016 + Directive 981/2024（2024年1月起生效） |
| **适用范围** | 年营业额 >500,000 ETB 的关联方交易 |
| **核心原则** | 独立交易原则 (Arm's Length Principle) |
| **文档要求** | 须保留同期文档 (Contemporaneous Documentation)；税务机关要求后45天内提供 |
| **处罚** | 应纳税额的20%（或20,000 ETB） |

### 4.5 2024-2026年重大税务变更

| 变更 | 详情 | 生效日期 | 来源 | 确定性 |
|------|------|----------|------|--------|
| **所得税重大改革** | 引入AMT、提高股息税至15%、收紧PE定义、简化纳税人分类、引入季度预缴 | 2025-07-08 | Proclamation 1395/2025 | ✅ 已确认 |
| **PE门槛收紧** | 服务/建筑类非居民企业PE认定从183天降至91天 | 2025-07-08 | Proclamation 1395/2025 | ✅ 已确认 |
| **纳税人分类简化** | 从三类(A/B/C)简化为两类：A(>200万ETB)和B(≤200万ETB) | 2025-07-08 | Proclamation 1395/2025 | ✅ 已确认 |
| **季度预缴制度** | A类季度结束后5天内、B类15天内预缴上年税额25% | 2025-07-08 | Proclamation 1395/2025 | ✅ 已确认 |
| **大额现金交易限制** | 单笔>50,000 ETB须通过银行转账或支票 | 2025-07-08 | Proclamation 1395/2025 | ✅ 已确认 |
| **数字服务税** | 非居民数字服务商纳入税收管辖 | 2025-07-08 | Proclamation 1395/2025 | ✅ 已确认 |
| **VAT改革** | 数字服务纳入VAT范围 | 2024-07 | Proclamation 1341/2024 | ✅ 已确认 |
| **转让定价指令更新** | Directive 981/2024 取代旧指令 | 2024-01 | Directive 981/2024 | ✅ 已确认 |
| **离岸资产转让征税** | 通过离岸实体间接转让埃塞资产需缴资本利得税 | 2025-07-08 | Proclamation 1395/2025 | ✅ 已确认 |

### 4.6 税收优惠

| 优惠类型 | 内容 | 条件 |
|----------|------|------|
| **SEZ 企业所得税** | 开发商/运营商：10年5%优惠税率；入驻企业：15%优惠税率 | 在经济特区运营 |
| **SEZ 关税/VAT** | 进出特区货物零关税、零消费税、零VAT | 在SEZ内运营 |
| **SEZ 红利税豁免** | 前5年红利分配全额免税 | SEZ企业 |
| **SEZ 外汇** | 100%外汇留存 | SEZ企业 |
| **优先领域优惠税率** | 2-6年15%优惠所得税率 | 绩效协议考核达标 |
| **科技初创企业** | 10年5%优惠税率 | 特定行业认定 |
| **固定资产投资补贴** | 第一年投资补贴（部分资本货物） | 2026年新引入 |

> ⚠️ **重要变化**：2026年《投资激励条例》(586/2026) 废除了自动长期免税期(Tax Holidays)，改为绩效挂钩的优惠税率模式。

### 4.7 外资特别影响

- 🔴 **PE门槛大幅收紧**：91天即构成常设机构（原183天），对跨境服务提供商影响重大
- 🔴 **股息税提高**：从10%升至15%，增加利润汇出的税务成本
- 🟡 **AMT制度**：即使亏损也可能需按营业额2.5%缴税
- 🟡 **季度预缴**：增加现金流管理压力
- 🟢 **SEZ优惠**：经济特区企业仍可享受显著税务优惠
- 🟢 **外汇改革**：出口商可留存50%外汇（SEZ企业100%）

## 5. 公司年审

### 5.1 当前有效规则

| 项目 | 要求 | 截止日期 |
|------|------|----------|
| **企业所得税申报** | 年度申报 | 会计年度结束后4个月内（约11月7日） |

| **商业记录保存** | ≥10年 | — |

### 5.2 审计要求

| 项目 | 说明 |
|------|------|
| **审计强制性** | 大多数公司须由合格外部审计师审计年度财务报表 |
| **审计用途** | 税务申报、银行贷款、股东大会、AABE合规审查 |

| **监管机构** | AABE 监督财务报告合规性 |

### 5.3 纳税人分类（2025年改革后）

| 类别 | 标准 | 税务处理 |
|------|------|----------|
| **Category A** | 年营业额 >200万 ETB | 按实际利润征税；须审计；季度预缴 |
| **Category B** | 年营业额 ≤200万 ETB | 主要按毛利/销售额征税；简化处理 |

> 🆕 原三类体系(A/B/C)已简化为两类（2025年7月起）

### 5.4 2024-2026年变更

| 变更 | 详情 | 来源 | 确定性 |
|------|------|------|--------|
| **纳税人分类简化** | 从三类简化为两类 | Proclamation 1395/2025 | ✅ 已确认 |
| **季度预缴引入** | 新增季度预缴所得税制度 | Proclamation 1395/2025 | ✅ 已确认 |
| **电子申报推进** | ERCA 逐步推行电子申报系统 | Ministry of Revenues | ✅ 已确认 |

### 5.5 外资特别影响

- 🟡 **审计师选择**：须确保审计师持有最新 AABE 执业许可
- 🟡 **季度预缴**：增加现金流管理复杂度
- 🟡 **记录保存**：10年保存要求，建议建立完善的数字会计系统
- 🟡 **无公司秘书要求**：目前不强制要求任命公司秘书，但须维护股东名册

## 6. 注销

### 6.1 当前有效规则

| 项目 | 说明 |
|------|------|
| **解散原因** | 章程期限届满、目的实现、成员决议、法院命令、破产 |
| **清算人** | 自愿清算由股东任命；强制清算由法院任命 |
| **债务清偿顺序** | 清算费用 → 员工工资福利 → 有担保债权人 → 无担保债权人 |
| **税务注销** | 须获得税务部门清缴证明 |
| **注销登记** | 向商业登记机关申请注销，终止法人资格 |
| **记录保存** | 清算完成后仍须保存商业记录 |

### 6.2 清算流程

1. **决定解散**：股东大会通过正式解散决议（须满足法定人数和投票要求）
2. **任命清算人**：股东（自愿）或法院（强制）
3. **通知与公告**：通知贸易部、税务部门，公告以便债权人申报
4. **资产盘点与处置**：清算人盘点资产负债
5. **债务清偿**：按法定优先顺序清偿
6. **编制最终资产负债表**：显示剩余资产分配情况
7. **税务审计**：获得税务清缴证明
8. **注销登记**：向商业登记机关申请注销

### 6.3 2021年商法典新增机制

| 机制 | 说明 |
|------|------|
| **非清算解散** | 一人有限公司在债务全部清偿后，资产可直接转移给所有者，无需全面清算 |
| **预防性重组** | 尚未达到支付不能（或不超过45天）的债务人可通过合同方式重组债务 |
| **重组程序** | 类似美国Chapter 11，旨在挽救有经营活力的企业 |
| **破产** | 仅在无法挽救时触发，涉及财产托管、资产拍卖 |

### 6.4 时间周期

| 类型 | 估计周期 |
|------|----------|
| 自愿清算（简单） | 6-12个月 |
| 强制清算 | 12-24个月+ |
| 非清算解散（一人公司） | 较短，具体视行政效率 |

### 6.5 2024-2026年变更

| 变更 | 详情 | 确定性 |
|------|------|--------|
| 无重大变更 | 2021年商法典修订后，注销规则在2024-2026年间未见重大修订 | ✅ 已确认 |

### 6.6 外资特别影响

- 🟡 **税务审计**：外资企业注销时税务审计可能更为严格
- 🟡 **外汇汇出**：清算所得汇出须满足 NBE 外汇指令要求
- 🟡 **EIC 参与**：外资企业注销可能需额外通知 EIC
- 🟡 **分支机构**：分支机构注销不终止母公司责任

## 📌 外汇管理要点（NBE）

> 核心法规：FXD/01/2024 号外汇指令（2024年7月发布，"绿色指令"）

| 项目 | 规则 |
|------|------|
| **汇率制度** | 向市场化汇率机制转型 |
| **出口回流** | 全部外汇收益须汇回授权银行，90天内 |
| **常规出口商留存** | 50% 存入外汇留存账户，50% 按市场汇率转换为ETB |
| **SEZ 企业留存** | 100% 外汇留存 |
| **服务出口商** | 100% 外汇留存，持有期限不限（2026年2月修订） |
| **留存资金使用** | 进口商品/服务、支付股息、偿还外债 |
| **持有期限** | 可无限期持有（2024年11月及2026年2月修订后） |
| **外资利润汇出** | 注册外资在满足文件要求后可合法汇出利润、股息、清算收益、股份转让所得 |
| **强制结汇取消** | 已取消过去向NBE强制结汇的规定 |

## ⚠️ 风险与建议

### 高风险领域

1. **PE门槛收紧（91天）**：跨境服务提供商需重新评估在埃塞俄比亚的活动安排
2. **外汇管制**：尽管改革，外汇管制仍然存在，利润汇出可能受实际操作影响
3. **法规变动频繁**：2024-2026年为密集改革期，需持续跟踪最新指令
4. **AMT制度**：即使亏损也需按营业额2.5%缴税，对初创/低利润企业影响大

### 建议复核事项

1. 货运代理行业外资持股限制取消的具体条文（2026年政策）
2. 银行业外资持股上限（40% vs 49%）的具体适用
3. 特定敏感行业的具体持股比例限制
4. SEZ优惠税率的具体绩效考核标准

### 建议行动

1. **税务合规升级**：尽快适应2025年所得税改革（AMT、季度预缴、PE新规）
2. **外汇策略**：评估是否通过SEZ运营以获得100%外汇留存优惠
3. **文档准备**：确保转让定价同期文档完备
4. **专业咨询**：鉴于法规变动频繁，建议聘请当地执业律师和税务顾问
